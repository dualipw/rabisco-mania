🌐 Conexão online

Para jogar pela internet com amigos em aparelhos diferentes, conecte um banco Firebase gratuito. Sem essa configuração, o jogo abre em modo de demonstração neste aparelho.

Configurar multiplayer online (uma vez)

1. Crie um projeto em console.firebase.google.com e adicione um app Web.
2. Ative Authentication → Sign-in method → Anonymous.
3. Crie Realtime Database e copie as regras de teste temporárias indicadas abaixo.
4. Cole os dados do app aqui e salve. Hospede este arquivo em um site HTTPS para seus amigos acessarem.

Regras temporárias de demonstração do Realtime Database (não use em um jogo público):
{ "rules": { ".read": true, ".write": true } }
Para publicar, configure autenticação, validação e regras seguras antes de divulgar.
